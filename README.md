## 🛠️ Contribution & Submission Workflow

All teams must follow the official fork-and-pull-request workflow:

1. **Fork this Repository**:
   - One team member should click the **Fork** button at the top right to fork this upstream repository to your personal/team GitHub account.
2. **Add Collaborators**:
   - In your forked repository, navigate to **Settings > Collaborators** and invite all your registered team members.
3. **Clone & Develop Locally**:
   ```bash
   git clone https://github.com/<your-username>/HFT26-TEAM-33.git
   cd HFT26-TEAM-33
   git checkout -b feature/prototype
   ```
4. **Commit & Push Regularly**:
   - Make atomic, descriptive commits throughout the hackathon.
   ```bash
   git add .
   git commit -m "feat: implement core solution architecture"
   git push origin feature/prototype
   ```
5. **Open Pull Request (PR) for Final Submission**:
   - When ready for evaluation, open a **Pull Request** from your fork's `main` branch back to this upstream repository's `main` branch.
   - **PR Title Format**: `[SUBMISSION] TEAM-33 - RiftX - Track Selection in Progress`
   - **PR Description Checklist**:
     - 📌 Solution Overview & Approach
     - 🏗️ Architecture & Tech Stack Details
     - 🚀 Local Setup & Installation Instructions
     - 🎥 Demo Video Link / Live Deployment URL
     - 📸 Key Screenshots & Visuals

## ResQ - Offline Emergency Mesh Chat

**What it does:** Phones talk directly to each other with no internet or
cell signal, using Google Nearby Connections (Bluetooth + Wi-Fi). Messages
hop from phone to phone, so people far apart can still be reached.

**Key features:**
- Phone-to-phone multi-hop messaging
- SOS alerts with siren and GPS location
- AES-256 end-to-end encryption
- Map and safe zones
- AI survival assistant

**Tech stack:** React, Vite, TypeScript, Capacitor, native Android (Java)

**Download the app:** (https://github.com/hydasim/HFT26-TEAM-33/releases/download/v1.0/app-debug.apk)

**How to run:**
1. Install the APK on 2 or more Android phones
2. Allow Bluetooth, location, and nearby device permissions
3. Open the app on both phones and they will connect
